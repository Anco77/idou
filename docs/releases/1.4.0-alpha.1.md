# 1.4.0-alpha.1 QA 构建记录

构建日期：2026-08-13

状态：内部 QA，不是正式发布，不创建 `v1.4.0` 标签，也不更新 `version.json`。

## 用户可见变化

- 批量补货/消耗改为全成全败；库存不足会逐项显示所需、现有和缺口，失败后保留选择。
- 首页、库存列表、批量页与色号详情使用同一个可配置低库存阈值；阈值修改后即时生效。
- 库存页明确区分加载、空、错误和数据状态，失败后可重试。
- 库存流水支持类型、最近 7 天和内部色号筛选，并按 50 条分页加载。
- 图纸扣库流水可以跳转原图纸；撤销会新增一次性冲正流水，原记录永久保留。

## 限制与正式版要求

- 这是 debug key 签名的 QA 包，不能覆盖安装使用正式 release key 签名的生产包，也不能上传正式发布渠道。
- 正式 `1.4.0` 必须提供 `android/key.properties` 与 release keystore；构建脚本在缺少正式签名时默认拒绝 production release 构建。
- 本机 Java 26 与当前 Android 编译链不兼容；本次仅对构建进程临时使用项目外层缓存的 JDK 21，没有修改系统全局 Java 配置。
- 当前没有已连接 Android 真机/模拟器，因此尚未完成安装、升级保留数据与真机离线冒烟。
- 图纸识别、编辑、转换和交付任务仍按任务板状态继续验收；该 QA 包不代表 `1.4.0` 功能冻结。
