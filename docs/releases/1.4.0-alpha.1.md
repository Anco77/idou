# 1.4.0-alpha.1 QA 构建记录

构建日期：2026-08-14

状态：内部 QA，不是正式发布，不创建 `v1.4.0` 标签，也不更新 `version.json`。

## 用户可见变化

- 批量补货/消耗改为全成全败；库存不足会逐项显示所需、现有和缺口，失败后保留选择。
- 首页、库存列表、批量页与色号详情使用同一个可配置低库存阈值；阈值修改后即时生效。
- 库存页明确区分加载、空、错误和数据状态，失败后可重试。
- 库存流水支持类型、最近 7 天和内部色号筛选，并按 50 条分页加载。
- 图纸扣库流水可以跳转原图纸；撤销会新增一次性冲正流水，原记录永久保留。
